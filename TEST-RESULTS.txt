CODE-LEVEL CHANGES REQUIRING WINDOWS ACCEPTANCE
- Quiet, non-activating six-second notices; no tray balloon or modal recovery
  dialogs; automatic role selection updates after replacement controller handles.
- Automatic mid-session USB reconnection with stable identity/source geometry
  verification, replacement handles, retained calibration and indefinite retry.
- Pointer read failures release the affected gesture while healthy contacts
  continue; source loss pauses corrected input and cancels all old gestures.
- Waiting/reconnected status, Stop/hotkey/Exit cancellation during recovery.
- Configured idle receiver timer: 25 ms -> 1,000 ms (40 -> 1 wakeup/sec).
  Active-contact timer: 30 ms, keeping held-contact updates.
- Reusable native buffers, reduced pipeline allocations, within-read movement
  merging, UI activity throttling, asynchronous stop and report collection.
- Per-user Windows sign-in registration; independent automatic profile restore;
  USB enumeration retry up to 60 seconds; identity/geometry checks; tray behavior.
- Named profile import/export and atomic default-profile persistence.
- Raw HID, pointer-device and WMI driver inventories, Device Manager errors,
  original-input two-finger/per-controller observations, runtime counters.

STILL NEEDS WINDOWS VERIFICATION
- Notice placement/DPI, silent appearance, no keyboard-focus theft, auto-dismiss,
  close/open actions, cooldown during repeated dropouts, and changed-layout notice.
- Stop and Start after a reconnect must use the updated controller selections
  without requiring Refresh or Identify.
- Unplug/replug either or both physical USB touch controllers during simultaneous
  touch, brief resets between polls, changed handles, and repeated interruptions.
- Reconnect must resume the original calibration without Identify/Refresh, with
  no stale touches; verify corners/edges and fresh simultaneous touch afterwards.
- Stop, Ctrl+Alt+F10 and Exit during recovery must prevent later automatic resume.
- Installer signing/trust and uninstall/startup cleanup in user registry hives.
- App UI, DPI/scrolling/tray controls and reopening an existing instance.
- Startup after reboot with immediate and delayed USB device arrival.
- Missing/swapped controllers, changed display bounds and source mapping.
- Native pointer capture/history and injection; retry behavior and jitter under
  actual load; CPU/memory when idle, moving and holding contacts.
- Physical simultaneous touch, clean releases, capture loss, Ctrl+Alt+F10,
  display/session/suspend handling, and drawing fidelity in target apps.
- New panel's Windows HID/multi-touch driver and physical two-finger delivery.
